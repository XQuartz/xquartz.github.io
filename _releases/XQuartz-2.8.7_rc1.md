### Changes in {{ page.version }} ###
  * All changes in [2.8.7_beta4](XQuartz-2.8.7_beta4.html) plus:
  * xserver: Fixed a use-after-free ([#524](https://github.com/XQuartz/XQuartz/issues/524))
  * xserver: Optimized repeated window resizing ([#499](https://github.com/XQuartz/XQuartz/issues/499))
  * mesa: Updated to 26.3.1 and worked around macOS 26+ bug that can misplace OpenGL surfaces that do not fully cover the containing window ([#513](https://github.com/XQuartz/XQuartz/issues/513))
  * freetype2: Enabled `hvf` for x86_64 and arm64 builds
