### Changes in {{ page.version }} ###
  * All changes in [2.8.7_beta3](XQuartz-2.8.7_beta3.html) plus:
  * xserver: Updated to xorg-server 26.1.0 RC4
  * xinit: `startx` now always passes `+byteswappedclients` ([#523](https://github.com/XQuartz/XQuartz/issues/523))
  * Restored the Mach-O compatibility and current versions of 17 libraries that the move to meson had lowered, so that binaries linked against the 2.8.5 libraries load again ([#525](https://github.com/XQuartz/XQuartz/issues/525))
  * Sparkle: Updated to 2.9.6
  * fontconfig: Updated to 2.18.4
  * freetype2: Updated to 2.15.0
  * mesa: Updated to 26.2.7, using llvm 23.1.6
  * Updated most of the X.Org libraries, applications, protocol headers, and utilities to their current upstream versions
